# 接口与证据门禁模板

适用：流式视频、异步输入、DMA缓冲及可回退的镜像部署。

- 将身份（器件、镜像签名、构建）与新鲜度（心跳、计数增量）分别验收。VIO刷新后重新绑定对象；观测冻结时先停止请求，不把旧值视为新事务失败。
- 将源完整帧、DMA写完成和显示所有权分开。SOF/像素送出不是DDR完成；ABORT后必须有DMA恢复契约，不能仅标无效后继续。
- 为连续/间歇输入、复位中断、背压和帧内模式请求建立独立黄金结果；断言数据、SOF/TLAST和停顿稳定性。
- 时序只对明确建模条件负责；不要把普通布线成功当板级输入窗口保证，不随意扩大false_path掩盖数据CDC。
- 部署前唯一识别目标，冻结旧版并核验备份，先临时写入/校验再切换，保留原始失败与一次性锁。遇身份或哈希异常停止，不猜编号。

失效边界：模板不替代具体芯片、引脚、电气或IP资料；没有强制终止、格式化、下载或重试的默认授权。
